## Logo Concepts

### 1. Fern + Document (`logo-fern-document.svg`)
Silver fern leaf integrated with a document/briefcase icon. Represents both NZ identity and the "brief" concept. Clean, symbolic, works well as an app icon.

**Best for**: Favicon, app icon, social media profile

### 2. Parliament + Newspaper Fold (`logo-parliament-fold.svg`)
Abstract parliament building (Beehive-inspired) merged with newspaper fold design. Emphasizes political news focus.

**Best for**: Header logo, main branding

### 3. Ballot Box + Kiwi Bird (`logo-ballot-kiwi.svg`)
Voting ballot box with simplified kiwi bird silhouette and check mark. Playful yet professional, distinctly NZ.

**Best for**: Campaign/election coverage branding, special features

### 4. Coat of Arms + Media (`logo-coat-of-arms.svg`)
Modern take on NZ coat of arms shield combined with newspaper lines and Southern Cross stars. Traditional meets contemporary.

**Best for**: About page, credibility/authority contexts

### 5. Wordmark (`logo-wordmark.svg`)
Typography-focused "THE BRIEF" with subtle fern frond in negative space and vote checkmark in underline. Minimal, scalable, readable.

**Best for**: Primary header logo, long-form content headers

## Usage Guidelines

### Light Mode
All SVGs work as-is on light backgrounds.

### Dark Mode
For dark backgrounds, consider:
1. Using CSS filters: `filter: brightness(0) invert(1);` for white versions
2. Creating alternate versions with white/light fills
3. Using the SVGs with transparent backgrounds and adjusting via CSS

### Favicon
Recommend: `logo-fern-document.svg` or `logo-ballot-kiwi.svg` (most recognizable at small sizes)
